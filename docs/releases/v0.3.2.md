**InstantReplay 0.3.2: library fixes.**

*En español abajo.*

## Fixes since 0.3.1

**Viewer library (Android)**
- **Select all respects the tag filter:** with a tag chip on, *Select all* selects only the clips shown. Changing the filter while selecting keeps only the clips still shown.
- **Export file name:** when every selected clip has the same tag, the joined video or ZIP is named `<session> - <tag>`.
- **Deleting a tag no longer untags clips:** the tag is no longer offered for new clips, but clips that had it keep it in the library, the filters, the live list and the review.

## Which file
- `instant-replay-0.3.2-arm64.apk`: almost every Android phone or tablet since 2017.
- `instant-replay-0.3.2-universal.apk`: older 32-bit devices.

## En español

**Correcciones de la biblioteca (Android)**
- **Seleccionar todo respeta el filtro de etiqueta:** con una etiqueta activa, solo se seleccionan los clips que se ven. Al cambiar el filtro durante la selección, solo se mantienen los clips que siguen visibles.
- **Nombre del archivo exportado:** si todos los clips seleccionados tienen la misma etiqueta, el vídeo unido o el ZIP se llaman `<sesión> - <etiqueta>`.
- **Borrar una etiqueta ya no se la quita a los clips:** deja de ofrecerse para clips nuevos, pero los clips que la tenían la conservan en la biblioteca, los filtros, la lista en directo y la revisión.

## Qué archivo
- `instant-replay-0.3.2-arm64.apk`: casi cualquier móvil o tablet Android desde 2017.
- `instant-replay-0.3.2-universal.apk`: dispositivos antiguos de 32 bits.
